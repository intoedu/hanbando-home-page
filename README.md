# 사단법인 한반도양식기술보급협회 홈페이지

Korea Peninsula Aquaculture Technology Association 공식 홈페이지 소스입니다.

별도의 설치나 빌드 과정 없이 **HTML 파일을 그대로 열면 바로 동작**합니다.
메모장이나 VS Code 같은 편집기로 직접 수정하실 수 있습니다.

---

## 2. 폴더 구조

```
├─ index.html 등 각 페이지 (.html)
└─ assets/
   ├─ css/style.css   ← 디자인(색상·글꼴·여백) 전체
   ├─ js/site.js      ← 연락처 정보, 메뉴, 기능 스크립트
   └─ img/            ← 기술 도해(SVG)와 사진 자리표시자
```

## 3. 자주 하는 수정 방법

### 연락처 · 주소 · 계좌 바꾸기
`assets/js/site.js` 맨 위 **SITE** 부분만 고치면 **모든 페이지에 한 번에 반영**됩니다.

```js
const SITE = {
  tel: '02-780-3880',            // 대표 전화
  mobile: '010-2600-2608',       // 휴대전화
  email: 'seoul4624@naver.com',  // 문의 양식이 도착하는 주소
  addressKo: '서울특별시 영등포구 국회대로 800, 604호',
  ...
};
```

### 메뉴 추가 / 삭제 / 이름 변경
같은 파일의 **NAV_ITEMS** 배열을 수정합니다.

```js
{ href: 'about.html', ko: '소개·인사말', en: 'About' },
```

### 글 내용 수정 (한글/영문)
본문은 아래처럼 한국어와 영어가 나란히 들어 있습니다. 필요한 쪽만 고치시면 됩니다.

```html
<span data-lang="ko">한국어 문장</span>
<span data-lang="en">English sentence</span>
```

### 사진 교체
`assets/img/` 폴더에 사진을 넣고, HTML의 `src="assets/img/파일이름"` 부분만 바꿔주세요.
현재 들어 있는 이미지는 사진을 받기 전까지 사용하는 **임시 이미지**입니다.

### 색상 바꾸기
`assets/css/style.css` 맨 위 `:root { ... }` 안의 색상 값만 바꾸면 사이트 전체 톤이 바뀝니다.

## 5. 운영 방식 (별도 프로그램 불필요)

이 홈페이지는 **깃허브 외에 어떤 서비스에도 가입할 필요가 없습니다.**
서버, 데이터베이스, 결제대행사, 외부 폼 서비스를 쓰지 않습니다.

### 문의 · 신청 · 후원 접수
온라인 양식을 쓰지 않습니다. **전화와 문자로 받습니다.**

각 페이지에 큰 버튼이 있고, 휴대폰에서 누르면 바로 통화 또는 문자 앱이 열립니다.

| 페이지 | 버튼 |
|---|---|
| 문의하기 | 대표전화 · 휴대전화 · 문자 · 이메일 |
| 신청·예약 | 전화 신청 · 문자 신청 · 이메일 신청 |
| 후원 | 후원 상담 전화 · 문자 신청 |

각 버튼 옆에 **"이것만 알려주세요"** 체크리스트를 넣어,
방문자가 전화할 때 무엇을 말해야 하는지 알 수 있게 했습니다.

번호를 바꾸려면 각 HTML의 `href="tel:027803880"` 부분과
`assets/js/site.js` 의 `tel` · `mobile` 값을 함께 고치면 됩니다.

### 나중에 온라인 접수를 붙이려면
신청 내역을 표로 쌓아 관리하고 싶어지면 저장할 곳이 필요합니다.
`assets/js/site.js` 의 **13번 항목 주석**에 Supabase 연결 코드 예시를 적어두었습니다.
그대로 따라 하면 되고, 공개 키가 브라우저에 노출되므로
Supabase 쪽에서 '쓰기만 허용' 보안 정책을 반드시 걸어야 한다는 점만 주의하면 됩니다.

### 게시판 (공지 · 소식)
글은 `news.html` 파일을 직접 고쳐서 올립니다. 아래 한 덩어리를 복사해 맨 위에 붙여넣고 내용만 바꾸세요.

```html
<div class="board__row" data-cat="notice">
  <span class="board__cat"><span data-lang="ko">공지사항</span><span data-lang="en">Notice</span></span>
  <a class="board__title" href="#">
    <span class="board__badge">NEW</span>
    <span data-lang="ko">여기에 제목을 적습니다</span>
    <span data-lang="en">English title</span>
  </a>
  <span class="board__meta">2026-08-13</span>
  <span class="board__meta">0</span>
</div>
```

`data-cat` 값은 분류입니다. `notice`(공지사항) / `edu`(교육 안내) / `news`(활동 소식) / `press`(보도자료).
검색 기능은 브라우저 안에서 바로 걸러내므로 따로 설정할 것이 없습니다.

### 후원
계좌 이체로 받습니다. 정기 후원(CMS)은 신청서를 접수받아 서면으로 처리합니다.
카드 결제를 붙이려면 결제대행사 가입이 필요하므로 넣지 않았습니다.

### 쓰지 않는 것
서버, 데이터베이스, 배포 플랫폼에 가입할 필요가 없습니다.

| 흔히 쓰는 것 | 이 사이트 |
|---|---|
| Supabase · Firebase (데이터베이스) | 쓰지 않음. 게시글은 HTML 파일에 직접 작성 |
| Vercel · Netlify (배포) | 쓰지 않음. 깃허브 페이지가 자동 배포 |
| Formspree 등 폼 서비스 | 쓰지 않음. 전화·문자로 접수 |
| 결제대행사(PG) | 쓰지 않음. 계좌 이체와 서면 CMS |
| Google Analytics | 쓰지 않음 |

### 외부에서 불러오는 것 (가입 불필요, 주소만 연결)

| 항목 | 설명 | 빼도 되는지 |
|---|---|---|
| 글꼴 (Pretendard) | 무료 공개 글꼴을 CDN 주소로 연결 | 빼도 됨. 맑은 고딕·애플 SD 고딕으로 자동 대체 |
| 지도 | `location.html`의 구글 지도 임베드 | 네이버·카카오 지도로 교체 가능. iframe 주소만 바꾸면 됨 |

영상(유튜브)은 협회 채널이 없어 현재 연결하지 않았습니다.
채널이 생기면 `gallery.html`의 안내 자리를 영상으로 바꾸면 됩니다.
