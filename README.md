# 사단법인 한반도 양식 기술보급협회 홈페이지

Korea Peninsula Aquaculture Technology Association — 공식 홈페이지 소스입니다.

별도의 설치나 빌드 과정 없이 **HTML 파일을 그대로 열면 바로 동작**합니다.
메모장이나 VS Code 같은 편집기로 직접 수정하실 수 있습니다.

---

## 1. 페이지 구성

| 파일 | 메뉴 | 내용 |
|---|---|---|
| `index.html` | 메인(홈) | 히어로, 협회 소개 요약, 주요 사업, 인사말, 소식, 영상, 갤러리, 협력기관 |
| `about.html` | 소개·인사말 | 협회장 인사말, 미션, 협회 개요, 연혁, 조직도 |
| `business.html` | 사업 안내 | 기술보급 / 해외시장 개척 / 기술향상 교육 / 해양 안전교육 |
| `news.html` | 공지·소식 | 게시판 목록, 카테고리 탭, 검색, 페이지네이션 |
| `gallery.html` | 갤러리 | 사진 갤러리(확대보기 포함), 영상 갤러리 |
| `location.html` | 오시는 길 | 지도, 사무국 안내, 교통편 |
| `apply.html` | 신청·예약 | 모집 과정 목록, 온라인 신청서 |
| `support.html` | 후원·헌금 | 정기(CMS)/일시/기관 후원, 계좌 안내, 후원 신청서 |
| `faq.html` | 자주 묻는 질문 | 카테고리별 아코디언 Q&A |
| `contact.html` | 문의하기 | 연락처, 온라인 문의 양식 |

## 2. 폴더 구조

```
├─ index.html 등 각 페이지 (.html)
└─ assets/
   ├─ css/style.css   ← 디자인(색상·글꼴·여백) 전체
   ├─ js/site.js      ← 연락처 정보, 메뉴, 기능 스크립트
   └─ img/            ← 이미지 (현재는 임시 이미지)
```

---

## 3. 자주 하는 수정 방법

### 연락처 · 주소 · 계좌 바꾸기
`assets/js/site.js` 맨 위 **SITE** 부분만 고치면 **모든 페이지에 한 번에 반영**됩니다.

```js
const SITE = {
  tel: '010-2600-2608',
  email: 'seoul4624@naver.com',
  addressKo: '서울특별시 ...',   ← 주소가 확정되면 여기 입력
  ...
};
```

### 메뉴 추가 / 삭제 / 이름 변경
같은 파일의 **NAV_ITEMS** 배열을 수정합니다.

```js
{ href: 'about.html', ko: '소개·인사말', en: 'About' },
```

### 글 내용 수정 (한글/영문)
본문은 아래처럼 한국어와 영어가 나란히 들어 있습니다. 필요한 쪽만 고치시면 됩니다.

```html
<span data-lang="ko">한국어 문장</span>
<span data-lang="en">English sentence</span>
```

### 사진 교체
`assets/img/` 폴더에 사진을 넣고, HTML의 `src="assets/img/파일이름"` 부분만 바꿔주세요.
현재 들어 있는 이미지는 사진을 받기 전까지 사용하는 **임시 이미지**입니다.

### 색상 바꾸기
`assets/css/style.css` 맨 위 `:root { ... }` 안의 색상 값만 바꾸면 사이트 전체 톤이 바뀝니다.

## 4. 아직 연결이 필요한 항목

실제 운영 전에 아래 항목은 정보를 받거나 외부 서비스 연결이 필요합니다.

| 항목 | 필요한 것 |
|---|---|
| 사무국 주소 · 지도 | 정확한 주소 → `location.html`의 지도 자리에 네이버/카카오/구글 지도 iframe 삽입 |
| 문의·신청 메일 수신 | `<form>` 태그에 `action` 주소 입력 (Formspree 등 외부 폼 서비스 또는 서버) |
| 게시판 | 관리자가 직접 글을 올리려면 별도 게시판 솔루션 또는 백엔드 연동 필요 |
| 후원 결제 | 카드·간편결제는 결제대행사(PG) 가입 후 연동 |
| 방문자 통계 | Google Analytics 스크립트 삽입 |
| SNS 링크 | 유튜브·인스타그램·페이스북·블로그 주소 |
| 로고 | 실제 로고 파일 (현재는 임시 심볼 사용) |
| 유튜브 영상 | 영상 또는 채널 주소 |
| 후원 계좌 | 은행명, 계좌번호, 예금주 |
| 연혁 | 실제 설립일 및 주요 활동 이력 |
